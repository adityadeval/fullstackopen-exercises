# Part 0 - Fundamentals of Web apps

[Part 0 overview](https://fullstackopen.com/en/part0) &nbsp;|&nbsp; [a. General info](https://fullstackopen.com/en/part0/general_info) &nbsp;|&nbsp; [b. Fundamentals of Web apps](https://fullstackopen.com/en/part0/fundamentals_of_web_apps)

Part 0 covers how a browser and a server actually communicate, before any application code is written. It works through an [example application](https://studies.cs.helsinki.fi/exampleapp) and covers:

- HTTP `GET` and `POST`, request and response headers, `Content-Type`, and status codes
- How the browser parses HTML, builds the DOM, and when scripts run during that process
- Fetching data with AJAX and `XMLHttpRequest`, and JSON as the transport format
- The difference between traditional server-rendered pages, AJAX-enhanced pages, and single page applications

There is no application code to submit for this part. The submitted exercises are sequence diagrams, written in [Mermaid](https://mermaid.js.org/syntax/sequenceDiagram.html) so that they render directly on GitHub.
