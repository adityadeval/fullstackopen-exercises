# Full Stack Open - Exercise Solutions

My solutions to the exercises from [Full Stack Open](https://fullstackopen.com/en/), the University of Helsinki's open online course in full stack web development, produced by its Department of Computer Science in collaboration with Houston Inc. The course is worth 5 to 14 ECTS credits and is the same material taught to the university's own computer science students.

## What the course covers

This is not an introduction to JavaScript syntax. It is an end-to-end engineering curriculum that runs from the browser to the database and out to deployment, built around the **MERN stack** and extending well past it.

**Frontend** - React, hooks, component architecture, client-side routing, advanced state management, custom hooks, CSS and webpack

**Backend** - Node.js and Express, REST API design, token-based authentication, user administration

**Databases** - MongoDB with Mongoose for document data, PostgreSQL for relational data

**Beyond REST** - GraphQL as an alternative API paradigm

**Type safety** - TypeScript applied across both frontend and backend

**Mobile** - React Native

**Delivery and operations** - CI/CD pipelines, and containerisation with Docker

**Testing** - unit, integration and end-to-end testing, applied throughout rather than bolted on

## Repository structure

One directory per part of the course. Where a part contains several distinct exercise sets, each set gets its own directory inside it.

```
part0/
part1/courseinfo/
part1/unicafe/
part1/anecdotes/
part2/courseinfo/
part2/phonebook/
part2/countries/
```

Every part directory has its own README.md explaining what that part covers, listing each exercise, and describing what was built.

The course is exercise-driven: each part develops a working application incrementally rather than asking for isolated snippets, so what is committed here is applications being built, not disconnected answers.
