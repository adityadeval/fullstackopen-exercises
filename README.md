# Full Stack Open - Exercise Solutions

My solutions to the exercises from [Full Stack Open](https://fullstackopen.com/en/), the open online course on modern JavaScript web development produced by the Department of Computer Science at the **University of Helsinki**, in collaboration with Houston Inc.

## What this course is

Full Stack Open teaches modern web application development in JavaScript. The main focus is building single page applications with **React** and REST APIs with **Node.js** and **Express**, together with the surrounding practice a real project needs: testing, configuration, environment management, and databases.

The course is exercise-driven. Each part builds a working application incrementally rather than asking for isolated snippets, so the commits here represent applications being developed rather than disconnected answers.

## Repository structure

One directory per part of the course. Where a part contains several distinct exercise sets, each set gets its own directory inside it.

```
part0/
part1/courseinfo/
part1/unicafe/
part1/anecdotes/
part2/courseinfo/
part2/phonebook/
part2/countries/
```

Every part directory has its own README.md explaining what that part covers, listing each exercise, and describing what was built.
